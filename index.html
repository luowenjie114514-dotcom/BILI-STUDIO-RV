蓝色大肥鱼自动化搬史

bili-studio 是一台跑在本机的 B 站自动化控制台。AI 读你的偏好、想关键词、 搜视频、写问候，然后替你发出去——评论区或私信，两种频道。 没有云端账号，没有遥测，cookie 只存在你自己的 data/config.json 里。

接口

无框架，ROUTES 表手写分发。全部仅监听 127.0.0.1。

去白边 + 羽化
bili-studio HTTP 接口清单
方法路径说明
GET/api/state全量状态：账户、名单、配置、版本、运行标志
POST/api/settings保存配置（深合并 + 备份 + 版本迁移）
POST/api/task/run立即执行一次任务
GET/api/schedules列出定时任务
POST/api/schedules新增 / 修改定时任务
POST/api/preview干跑：只生成不发送，返回字数与上限
GET/api/logs?since=增量拉日志（序号续传）
GET/api/changelog读 CHANGELOG.md，前端渲染 markdown
GET/api/task/history?n=任务历史（默认 30，最多 200）
POST/api/task/history/clear清空历史（内存 + 磁盘）
POST/api/accounts/test测活：验 cookie 是否有效
POST/api/accounts/health批量验活，返回四态健康点
GET/api/term?since=终端输出增量拉取
POST/api/term/exec在服务进程里执行一条命令
POST/api/term/kill终止正在跑的命令（taskkill /t /f）
POST/api/term/clear清空终端缓冲区
GET/api/theme读当前配色（8 组 50 项）
POST/api/theme保存配色到 config.json
POST/api/skin/upload上传皮肤图片
POST/api/shutdown关闭服务
POST/api/logs/clear清空日志
07

边界

放慢节奏、前置拦截，而非绕过限制。

01

失效即拦

任务开始前验活当前账户，失效直接中止，一条不发。

assertAccountUsable() → 60s 内复用结果
02

节流 + 日限

默认间隔 12 秒，每日 10 条封顶。计数按账户独立统计。

task.delaySeconds = 12 · task.dailyLimit = 10
03

不自发

名单含当前账户本人即跳过，且在按次数切片之前，不占名额。

code=21026 → 前置过滤
04

不假装成功

网页端仅放开 msg_type 1/2/5，分享卡片（7）恒返回 -400。先试卡片，失败降级为「文本 + 链接」。

try card → fallback text+url
05

cookie 即密码

仅存于本地 data/config.json，不外传、不入日志、不入 git。

0600 · 日志字段打码
08

版本

全量改动见 CHANGELOG.md，控制台右上角可查。

v1.5.4 · 当前

整套配色都能自己调

主题色从「只有主色和副色」变成 8 组、50 项逐项编辑：底色、日志每一级的颜色、终端、更新日志弹窗全都可调。派生半透明色由主色现算，不再出现换了橙色还留着青色焦点圈的事。配色同时写进 config.json，换浏览器不丢。

v1.5.3

拆模块、迁配置、一键测试

后端从两千行单文件拆成七个模块，前端拆成七个片段但构建时仍拼回单个 app.js；配置加了版本号与迁移链；任务历史落盘到 data/history.jsonl，重启不丢；一套命令跑完全部测试。

v1.5.2

「AI 接口分区废了」其实只是够不着

窗口排布无视视口高度，把 AI 接口窗连同保存按钮推到页面 1500px 以外。修法是操作按钮吸在窗口底边，排布按视口走，窗口菜单还多了「排回屏幕」。

v1.5.1

私信不再搔首弄姿

以前模型看到标题就开始演——「你也太懂我了吧」。改成转述「我今天刷到了什么」，提示词给正反例；同时加了正文字数上限（默认 40 字，截到分句）。

v1.5.0

把控制台整个松开

九个分区全部变成可拖动 / 可收起 / 可关闭的小窗，顶栏多了「▦ 窗口」菜单和「▣ 终端」，7 套主题色，标题改成「蓝色大肥鱼 · 自动化搬史」。

v1.4.0

多一个频道：私信

勾选即改为发私信而不发评论，内容由文案 + 署名构成；⚙ 面板选「原生卡片 / 文本 + 链接」；自动任务也支持私信。

v1.3.0

AI 接口不再绑死一家

任何 OpenAI 兼容供应商都能接：供应商预设、三种鉴权 + 免鉴权、完整端点覆盖、额外请求头。修掉 response_format 不兼容、Base URL 拼错、429/5xx 不重试、```json 围栏解析失败等五个坑。

v1.2.0

双击即用

启动自动开浏览器、把 PE 子系统改成 GUI 干掉黑窗口、网页一键关闭、重复双击不打架、启动失败给可视化错误页。

v1.1.0

能打包、能换皮、更抗造

独立 exe 打包、皮肤更换（含图片导入）、cookie 解析升级为请求头关键词精准定位，并修掉一个会让配置「整个消失」的深合并崩溃。

v1.0.0

首个可用版本

账户 / 名单 / 偏好 / 风格 / 署名 / 立即执行 / 自动任务 / 干跑 / 日志 / 历史，一次到位。
